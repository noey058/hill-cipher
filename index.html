01 / Letter encoding

Each English letter corresponds to an integer from 0 through 25. The message is grouped into column vectors with n letters each.

02 / Valid key

A key matrix K is invertible modulo 26 exactly when gcd(det(K), 26) = 1. Only then can every message be decrypted uniquely.

03 / Padding

Encryption pads a short final block with X. When decrypting, any added X may need to be removed manually.
